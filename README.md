# INDISCUTÍVEL HUB — Demonstração para GitHub Pages

Esta entrega preserva os layouts originais enviados e conecta as telas em uma navegação demonstrativa.

## Como publicar
1. Extraia o ZIP.
2. Envie `index.html`, `manifest.json` e a pasta `pages` para a raiz de um repositório GitHub.
3. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Aguarde o GitHub gerar o link público.

## Perfis de demonstração
Na tela de login, use um e-mail contendo `aluna` para entrar no perfil Aluna (ex.: `aluna@demo.com`). Qualquer outro e-mail de demonstração abre o perfil Mentora/Admin (ex.: `mentora@demo.com`). A senha pode ser fictícia, pois esta entrega não possui backend.

## Escopo
- 6 telas de acesso/login
- 14 telas da Mentora/Admin
- 25 telas da Aluna
- 5 telas de estados/componentes preservadas na pasta `pages`
- Navegação entre os principais fluxos e feedback visual para ações simuladas

Esta é uma demonstração front-end. Envio real de e-mail, banco de dados, autenticação segura e pagamentos exigem backend/serviços externos na versão de produção.
